Internals

These functions and types are not part of the public API (they are not exported), but are documented here for contributors. They may change without notice.

Execution-backend helpers

The execution-axis introspection helpers (local_backend, is_distributed, resolve_backend) are provided by ComputationalBackends.jl and used internally and by the distribution extensions. The default AutoBackend resolves through the internal _resolve_execution (Threaded when OhMyThreads is loaded and Threads.nthreads() > 1, else Serial); ComputationalBackends' own resolve_backend(::AutoBackend) raises.

FlowFieldSpectra._backend_nthreads — Function
_backend_nthreads(exec) -> Int

Thread count for a library plan built under exec: Threads.nthreads() on a threaded backend, 1 otherwise. Every library plan FFS builds itself receives this explicit count, since FINUFFT reads 0 as every core on the machine. A host NUFSHT plan takes execution = exec and sets the same count from it; a device one, built over device nodes, takes this count.

Reusable Cartesian direct-sum plan: the per-axis dense DFT matrices, the working arrays the contraction walks through, the wavenumber axes, the modes held at zero, and the quadrature-scaled field buffer, all built once for a fixed grid, ms, iflag and batch shape. FlowFieldSpectra.DirectSumSynthesisPlan — Type
DirectSumSynthesisPlan{FT}

Reusable direct-sum synthesis: the grid, resolution, sign and batch shape the series is fixed by, so synthesize! writes into the caller's array and allocates nothing of its own.

The plan holds what the synthesis reads from the grid (DirectSum.synth_setup): on a tensor grid the per-axis tables and the working arrays their contraction walks through, on a Cartesian point set the positions and wavenumbers, and on a sphere the nodes and Legendre tables.

FlowFieldSpectra.HybridPlan — Type
HybridPlan{T,D,R}

Reusable plan for a Cartesian grid uniform in some directions and stretched in others, on the host or a device: the FFT over the uniform axes (RegionFFT), one 1-D type-1 NUFFT per stretched axis, the length(sdims) + 1 working arrays the passes write through, the last in the coefficients' layout, and the per-point weights the field is staged with. FlowFieldSpectra.RegionFFT — Type
RegionFFT{P,S,O}

The hybrid composite's FFT over its uniform axes, planned once on the execution backend's arrays. A real field takes an rfft, which shortens axis 1 to n₁÷2+1. conj_in conjugates a complex input, carrying iflag = -1 through the composite. The field is staged into scratch with its quadrature weights, so the caller's array is never mutated.

NUFFT plans

The NUFFT plans run FlowTransformBindings' library plans in FFTModes order and publish the packed layout from them: a point set's type 1 and type 2, and a nonuniform tensor grid's separable passes in both directions. A line pass of the separable plans and the hybrid composite asks NonuniformFFTs for m_d modes and reads, or writes, the mode +m_d/2 of a widened axis in each line's oversampled spectrum; it asks FINUFFT for the box's m_d + 1 modes.

FlowFieldSpectra.NUFFTPointPlan — Type
NUFFTPointPlan{T,D,R}

Reusable type-1 NUFFT over a Cartesian point set (a node cloud or a curvilinear grid's cells): the FlowTransformBindings plan with C transforms per execution, its strength and spectrum buffers, and the tables that publish the coefficient box. R marks a real field. Execute with calculate_spectrum!(coeffs, plan, field); close! releases the library plan.

NUFFTSeparablePlan{T,D,R}

Reusable separable NUFFT over a nonuniform tensor-product Cartesian grid: one NUFFTAxisPass per axis, the working arrays the passes write through, and the per-point weights the field is staged with. Execute with calculate_spectrum!(coeffs, plan, field); close! releases the library plans.

source
FlowFieldSpectra.NUFFTSeparableSynthesisPlan — Type
NUFFTSeparableSynthesisPlan{T,D,R}

Reusable synthesis on a nonuniform tensor-product Cartesian grid, the counterpart of NUFFTSeparablePlan: one type-2 NUFFTAxisPass per axis in sdims order, the working arrays the passes write through, and a real field's axis-1 row weights. Execute with synthesize!(out, plan, coeffs); close! releases the library plans.

source
FlowFieldSpectra.NUFFTAxisPass — Type
NUFFTAxisPass

One grid axis's 1-D NUFFT over C lines per execution. On the host its executions are split over lanes, one task each, every lane with a single-threaded library plan, its own strength and spectrum buffers and line offsets: a library plan threaded over a few short lines costs more than the lines. On a device, one plan and the staging for the axis-to-front permutation.

A line's m output modes are the library's spectrum rows 1:kept in order, rows past gap one row on, and on a NonuniformFFTs pass whose output widens to ms_d + 1 modes the row +ms_d/2 between them, held in each line's oversampled spectrum (_LinePlus).

FlowFieldSpectra._axis_pass — Function
_axis_pass(library, exec, ::Type{LT}, insize, d, axis, n, b, rng, off, tol, batch_chunk; iflag)

The NUFFTAxisPass along dim d of a working array of size insize on its points side, whose lines have element type LT: an n-mode transform whose coefficient box holds b modes on this axis (n or n + 1), written to b output modes for a complex line and the half b ÷ 2 + 1 for a real one. iflag is FlowTransformBindings' sign.

FlowFieldSpectra._LinePlus — Type
_LinePlus

Where a NonuniformFFTs line plan of n modes holds the mode +n/2 of an output widened to n + 1 modes (active): output row pos[1], entry idx[1] of each line's oversampled spectrum, which the type 1 reads times read[1] = normfactor / ϕ̂(n/2) and the type 2 writes times write[1] = 1 / ϕ̂(n/2) (FlowTransformBindings.oversampled_spectra). The tables live in the plan's memory, where the device gathers read them.

source
FlowFieldSpectra._half_row_weights — Function
_half_row_weights(library, ::Type{T}, m1, b1) -> Vector{T}

The weight each row k₁ = 0 … b1÷2 of a real field's packed half enters the axis-1 type 2 with, m1 the transform's and b1 the coefficient box's axis-1 mode count, so the pass sums the whole box. NonuniformFFTs' real-data plan counts each row past k₁ = 0 with its mirror: 1/2 on a Nyquist row the box does not widen, 1 elsewhere. FINUFFT's complex plan reads no mirror: the row's fold weight, 2 past k₁ = 0 but on that Nyquist row.

FlowFieldSpectra._packed_src — Function
_packed_src(ms, box, dims, ::Type{T}; mirror = true) -> Vector{Int}

For each coefficient of the box box of an ms-mode transform of a field of element type T, axis 1 halved for a real T, where one transform's spectrum of shape dims in FFTModes order holds it: i > 0 at entry i, i < 0 as the conjugate of entry -i, 0 nowhere. A computed mode is read at its frequency, dims holding at least the computed modes on every axis. A mode at +ms_d/2 on a widened axis is read at its frequency where dims[d] > ms[d] on each such axis, as the conjugate at -k where mirror is set and -k is computed (dims then holding -k₁ on axis 1), and is 0 otherwise; with -ms_e/2 on another widened axis it is 0.

source
FlowFieldSpectra._oversampled_table — Function
_oversampled_table(Tr, ms, box, ovdims, phis, scale) -> (pos, src, fac)

The coefficients of a real field's packed box box at +ms_d/2 on a widened axis that hold a value, and where a real-data NonuniformFFTs plan of ms modes holds them in its oversampled spectrum of shape ovdims (FlowTransformBindings.oversampled_spectra): coefficient pos[i] is entry src[i] times fac[i] = scale / Π_d phis[d]. The forward reads them at scale = normfactor / M, the factor the plan's own modes take with FFS's 1/M; the synthesis writes them at scale = 1 and divides (FlowTransformBindings.oversampled_type2!).

source

_gather_packed!(dst, doff, src, soff, sstride, idx, scale, n, ntr, neg)

_scatter_each!(dst, doff, n, srcs, ntr, pos, idx, fac, neg)

FlowFieldSpectra._mode_src — Function
_mode_src(T, ms, box) -> (src, w)

For each mode of a real-data plan over ms modes, its packed half in FFTModes order, the entry src of one field's packed half over the coefficient box box holding the same frequency, and the weight w it enters with: 1/2 on the row k₁ = ms₁/2 of an even axis 1 the box does not widen, a Nyquist row the plan's type 2 counts with a mirror it does not have, 1 elsewhere.

The direct sum's setup / run split

Both direct-sum plans are a setup the grid fixes plus a run over a field, and each one-shot composes the same pair. On a Cartesian grid the setup holds the per-axis dense DFT matrices, the working arrays the contraction walks through and the modes a real field's coefficient box holds at zero; a structured grid contracts axis by axis through AxisPass, and a point cloud sums directly.

FlowFieldSpectra.DirectSum.phase_geometry — Function
phase_geometry(grid, ::Type{FT}, ms, ::Type{T}, box = nothing) -> (xs, ks)

The positions x - x₀ and the wavenumber axes a Cartesian direct sum over grid reads, over the coefficient box of an ms-mode transform (Grids.mode_box) of a field of element type T, halved for a real T. box holds a whole grid's origins and Fourier lengths when grid is part of it (see Grids.axis_geometry).

FlowFieldSpectra.DirectSum.cart_setup — Function
cart_setup(layout, grid, T, ms, batch, iflag; box = nothing) -> NamedTuple

Everything a Cartesian direct sum reads from grid: the wavenumber axes of the coefficient box, the modes of a real field's packed half that hold zero (FlowTransformBindings.outside_modes), and for a tensor layout the per-axis DFT matrices and the working arrays their contraction walks through. T is the field's element type, whose realness fixes the packed layout; box is as in phase_geometry.

Run it against a field with cart_run!, or the threaded run of the OhMyThreads extension; DirectSumCartesianPlan holds it across executions.

Fill coeffs with the Cartesian spectrum of field against a cart_setup result, the modes outside the computed box and its mirror at zero, and return the wavenumber axes.

FlowFieldSpectra.DirectSum.synth_setup — Function
synth_setup(layout, grid, T, ms, batch, iflag; box = nothing)

Everything a Cartesian direct-sum synthesis over grid reads, for a field of element type T. On a tensor grid, the native_table a real field's packed half is read through, and the per-axis tables E_d[p, a] = exp(+iflag·i·k_a·x_p) with the working arrays their contraction walks through from the series of Grids.series_modes (…, batch…) to the field (size(grid)…, batch…). On a point set, the positions and the wavenumbers of the coefficient box its direct sum reads (phase_geometry). box is as in phase_geometry.

source
FlowFieldSpectra.DirectSum.native_table — Function
native_table(ms, box) -> (src, wt)

How the complex series in FFT order whose real part is the series of a real field's packed half over box reads that half, box the coefficient box of an ms-mode transform (Grids.mode_box). The series has (box[1], ms[2:D]…) modes. Mode i (linear) is entry src[i] of one field's half, or the conjugate of entry -src[i] where src[i] < 0 (k₁ < 0), times wt[i]. The weight is two where -k is not a mode of the series (k_d = -ms[d]/2 on an axis d ≥ 2 that box widens) and one elsewhere, so the real part sums k and -k alike.

Grids

FlowFieldSpectra builds on FlowGeometries' grid/geometry types and reads them through FlowGeometries' own accessors. The grid-related internals are the spectral wavenumber grid, the field-shape and point-list readers, the spherical (θ, φ) / quadrature-weight bridge (FlowGeometries stores (λ, φ_lat); the transforms want (θ = colatitude, φ = longitude)), the spherical layout traits that select an algorithm, and the mask/measure queries.

FlowFieldSpectra.Grids.physical_wavenumbers — Function
physical_wavenumbers(Ls, box, ::Type{T}) -> NTuple
physical_wavenumbers(grid, ms, ::Type{T}) -> NTuple

Packed native-order wavenumber axes matching the packed coefficient layout of a field of element type T: for a real T axis 1 is a nonnegative rfft axis (FlowTransformBindings.RFFTAxis, length box[1]÷2+1) and axes 2:D are full fft axes (FlowTransformBindings.FFTAxis); for a complex T every axis is a full fft axis. box[d] is the coefficient box's mode count along d, which on grid is the mode_box of an ms-mode transform. A Fourier length of zero takes the spacing of unit length.

PointwiseCartesian

Cartesian grids whose coordinates are stored per point: a node cloud, and a curvilinear grid, whose coordinate arrays hold one value per cell. Both index linearly in the field's own order. A tensor grid has its own, more specific, factorized methods.

FlowFieldSpectra.Grids.SphericalHarmonicGeometry — Type
SphericalHarmonicGeometry

Geometries whose points are addressed by a direction, so a spherical-harmonic transform applies to a field sampled on them: a sphere, and a spheroid.

A spheroid node's direction is its geocentric one, which _colatitude gives, and the transform returns the field's surface expansion over those directions.

FlowFieldSpectra.Grids._sph_points — Function
_sph_points(grid) -> (θ, φ)

Per-point colatitude/longitude lists for any spherical grid, in the transform's (θ = colatitude, φ = longitude) convention and the field's column-major order (longitude fastest on a structured (nlon, nlat) grid). FlowFieldSpectra.Grids._colatitude — Function
_colatitude(geometry, φ) -> FT

Colatitude of the direction the surface point at latitude φ lies in: π/2 less its Geometry.geocentric_latitude, which is φ on a sphere and the direction of the geodetic φ's point on a spheroid. Longitude does not enter, so a latitude row is one iso-latitude ring.

source
FlowFieldSpectra.Grids._longitude_axis — Function
_longitude_axis(grid, ::Type{FT}) -> (λ₀, s)

The origin λ₀ and step sign s of a structured sphere's longitude axis, which a longitude FFT reads only as a FlowGeometries.Axes.PeriodicUniformAxis: nlon samples 2π/nlon apart around the circle. With λ_j = λ₀ + s·2πj/nlon, Σ_j f_j e^{-imλ_j} is e^{-imλ₀} times the FFT's bin s·m.

_colocated(a, v) -> AbstractArray

Spherical layout routing

FlowFieldSpectra.Grids._sph_layout — Function
_sph_layout(grid) -> FlowGeometries.Grids.AbstractRingStructure

Which spherical transform grid takes, named by FlowGeometries.Grids.ring_structure: TensorRings() is the tensor path, one longitude matrix shared by complete latitude rows under a sphere's latitude quadrature; IsoLatitudeRings() the ring path, a longitude sum per ring; NoRings() the per-point projection. A tensor grid with a mask, whose rows are incomplete, or on a spheroid, whose latitudes are geodetic, takes the ring path.

source
FlowFieldSpectra.Grids._ring_table — Function
_ring_table(grid, ::Type{FT}; lmax=nothing, sampling=nothing, weights=nothing) -> (; ranges, θ, λ, wpt)

Per iso-latitude ring: its slice of the flattened point vector and its colatitude, read at the ring's first point; plus every point's longitude and quadrature weight. The weights are _sph_point_weights(grid, FT; sampling, weights), the ones the per-point projection reads, so the ring transform is that projection reassociated for every quadrature a caller can state.

Quadrature, band limit, masks

FlowFieldSpectra.Grids._sht_weights — Function
_sht_weights(grid, nlat; sampling=nothing, weights=nothing, lmax=nothing) -> Vector

Per-colatitude quadrature weights for a structured spherical grid, from its own node-set recipe FlowGeometries.Grids.sampling(grid) via SphericalSampling.latitude_weights (Σw = 2, carrying the sinθ Jacobian). weights or sampling override it; lmax is checked against the band limit.

Coordinates alone do not fix the quadrature, so a grid built from raw axes, which records no recipe, raises unless the caller states one.

source
FlowFieldSpectra.Grids._sph_point_weights — Function
_sph_point_weights(grid, ::Type{FT}; sampling=nothing, weights=nothing) -> AbstractVector{FT}

Per-point quadrature weights of a spherical grid in the field's column-major order, an inactive point at zero: on a structured sphere the latitude rule of _sht_weights times 2π/nlon, and on every other grid the per-node weights of _sph_node_weights. Both total 4π over an unmasked grid. sampling and weights override the grid's own rule as those two state, so weights holds one value per latitude on a structured sphere and one per node elsewhere.

source
FlowFieldSpectra.Grids._sph_node_weights — Function
_sph_node_weights(grid, ::Type{FT}, N, weights) -> Vector{FT}

Per-node quadrature weights for a scattered spherical grid, from its own per-node measure rescaled to sum to 4π — the transform's convention, the same total the structured path's latitude_weights ⊗ 2π/nlon carries. weights overrides it, one per node, an inactive node still at zero. Only the relative measures matter, so a grid of true dual-cell areas integrates exactly and a grid of equal-area nodes gives 4π/N.

source
FlowFieldSpectra.Grids.quadrature_scale — Function
quadrature_scale(grid, ::Type{FT}, N) -> Union{Nothing, AbstractVector}

Per-node factor α_j = N·w_j/Σw taking a node-count-normalized transform to the measure-weighted quadrature over grid, or nothing where the measure's type makes it constant (a rectilinear grid's SeparableMeasure of Axes.ConstantVector factors, every axis uniform) and α_j is exactly one. N is the number of spatial samples the field carries; the result is flat, of length N, in the field's column-major point order.

Read from FlowGeometries.Grids.measure, which keeps a rectilinear grid's SeparableMeasure and a ring layout's RingwiseVector compact, so the result is lazy on such a grid.

Packed spectral layout

FlowFieldSpectra.Grids.mode_box — Function
mode_box(grid, ms, ::Type{T}) -> NTuple

The extents of the coefficient box an ms-mode Cartesian transform on grid of a field of element type T fills. For a real T, an even ms[d] on an axis whose samples tell +ms[d]/2 from -ms[d]/2 apart widens to ms[d] + 1 (FlowTransformBindings.box_size), so that the packed half reaches every conjugate partner; a uniform axis of a structured grid transformed at its own length samples the two as one mode and keeps ms[d]. A complex T's box is ms.

source

The packed layout and the widened axes are FlowTransformBindings' (box_size, outside_modes). The NUFFT and hybrid plans publish the half over the coefficient box from a library's FFTModes output through one index table (FlowFieldSpectra._packed_src) of direct and conjugate reads. A NonuniformFFTs plan asked for ms_d modes reads the modes at +ms_d/2 a widened axis adds from its oversampled spectra, and its synthesis writes them there: a real-data point plan through FlowFieldSpectra._oversampled_table, a line pass through FlowFieldSpectra._LinePlus, on the host and on a device alike.

FlowFieldSpectra.Preprocessing.axis_taper — Function
axis_taper(::Type{FT}, window, n) -> Vector{FT}
